// จัดการเรื่องล็อกอินหรือสมัครสมาชิก (พร้อมแจ้งเตือนแบบละเอียด) async function handleAuth() { const email = document.getElementById('emailInput').value; const password = document.getElementById('passwordInput').value; if (!email || !password) { alert("กรุณากรอกอีเมลและรหัสผ่านให้ครบถ้วนครับ"); return; } if (isLoginMode) { const { error } = await _supabase.auth.signInWithPassword({ email, password }); if (error) { // เช็กข้อความ error จาก Supabase แล้วแปลงเป็นภาษาไทยที่เข้าใจง่าย if (error.message.includes("Invalid login credentials")) { alert("เข้าสู่ระบบไม่สำเร็จ: อีเมลหรือรหัสผ่านไม่ถูกต้องครับ"); } else { alert("เกิดข้อผิดพลาด: " + error.message); } } else { location.reload(); } } else { const { error } = await _supabase.auth.signUp({ email, password }); if (error) { if (error.message.includes("Password should be at least")) { alert("สมัครสมาชิกไม่สำเร็จ: รหัสผ่านต้องมีความยาวอย่างน้อย 6 ตัวอักษรขึ้นไปครับ"); } else { alert("สมัครสมาชิกไม่สำเร็จ: " + error.message); } } else { alert("สมัครสมาชิกสำเร็จ! กรุณากดสลับไปที่โหมดเข้าสู่ระบบได้เลยครับ"); toggleMode(); } } }
